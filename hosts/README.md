# Hosts

This directory documents how to configure the hosts of the m3w.ch setup:

- [`nas.m3w.ch`](./nas.m3w.ch/README.md)
- [`offsite.m3w.ch`](./offsite.m3w.ch/README.md)
- [`raspberry.m3w.ch`](./raspberry.m3w.ch/README.md)

The hosts running [Doco-CD](../apps/doco-cd/README.md) also store the list of
applications to deploy in their directory, in a `.doco-cd.yaml` file.
